# קבצים אמיתיים לתיבת הדמו (רשות)

קובץ שנמצא כאן ושמו זהה לשם בטבלה נכנס לתיבת הדמו כמו שהוא. אם הקובץ חסר, הסקריפט `demo/generate_demo_mailbox.py` מייצר במקומו קובץ חלופי: תמונה צבעונית, צליל או וידאו ריק.
בשלב 1 המערכת משתמשת רק בשם הקובץ ובהקשר של המייל. קבצים אמיתיים יהיו שימושיים בשלב 2, כשנוסיף מודל ראייה.

**חשוב:** הקבצים האלה נכנסים להגשה. אסור שיהיו בהם אנשים אמיתיים, פרטים מזהים או מידע אישי. כל קובץ צריך להיות קטן מ-2MB.
